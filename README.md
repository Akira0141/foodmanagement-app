# 食材在庫管理アプリ

このリポジトリは「食材在庫管理アプリ」の実装を進めるためのコードベースです。

概要
- 技術スタック: Next.js (React) + Supabase (Postgres + Auth + Storage)
- 対象: 個人利用（自分用）
- 目的: どこに何をしまったか忘れて重複購入、食材の劣化を防ぐ

主要機能（ミニマムで実用化する優先機能）
1. 食材の登録（名前、数量、単位、保管場所、購入日、賞味期限、メモ）
2. 一覧表示（賞味期限順、保管場所などでソート／フィルタ）
3. 入力時に絵文字を自動割当（絵文字で代替）
4. 賞味期限が未入力の場合は一般的な期間を提案
5. 期限が近いものを視覚的に強調

ローカル開発手順（概略）
1. リポジトリをクローン
2. .env.local を作成して Supabase URL / ANON KEY を設定
3. npm install
4. npm run dev
